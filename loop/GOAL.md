# GOAL（人間が書く。エージェントは編集しない）

## 目的
西暦の日付と和暦の文字列を相互に変換する小さなライブラリ `src/wareki.mjs` を作る。
`toWareki(date)` と `parseWareki(str)` の2つを名前付きでエクスポートする。

## 完了条件（すべて機械的に確認できること）
- [ ] `loop/loop.config.json` の verify コマンド（`npm test`）が成功する
- [ ] `tests/wareki.test.mjs` のテストがすべて通る（テストは人間が書いた仕様。変更しない）
- [ ] `toWareki(date)` が `"令和8年10月26日"` の形を返す（1年目は「元年」、月日はゼロ埋めしない）
- [ ] `parseWareki(str)` が漢字表記・略記（`R8.10.26`、英字は大文字・小文字とも）・全角数字・前後の空白を受け付け、その日の 0:00（ローカル時刻）の Date を返す
- [ ] 範囲外・存在しない日付・不正な書式には RangeError、型が違う入力には TypeError を投げる

## 仕様
元号の開始日（この日から新しい元号。前日までは前の元号）:

| 元号 | 略記 | 開始日 |
|---|---|---|
| 明治 | M | 1868-10-23 |
| 大正 | T | 1912-07-30 |
| 昭和 | S | 1926-12-25 |
| 平成 | H | 1989-01-08 |
| 令和 | R | 2019-05-01 |

- 和暦の年 = 西暦の年 − 元号の開始年 + 1
- 明治の開始日より前は扱わない（RangeError）
- 日付はすべてローカル時刻で扱う
